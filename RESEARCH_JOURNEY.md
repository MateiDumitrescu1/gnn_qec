# GNN Decoder Research Journey

## Summary

This project explored whether a Graph Neural Network decoder can learn to predict logical observable flips from surface-code detector syndromes generated by Stim. The baseline comparison was PyMatching's MWPM decoder, which acts as the legacy/control method because it uses the detector error model directly.

The work progressed in three stages:

```text
Run 1: simple active-defect GNN        -> underperformed MWPM
Run 2: fixed detector-location GNN     -> improved substantially, still below MWPM
Run 3: optimized residual GNN decoder  -> reached 80% accuracy and beat MWPM
```

All runs used simulated QEC data generated from a Stim `surface_code:rotated_memory_z` memory circuit. Each shot is one independent simulated run of the same surface-code experiment, producing a detector-event vector and a binary logical-flip label.

## Problem Setup

The learning task is graph-level binary classification.

```text
Input:  detector events / syndrome defects from one Stim shot
Output: predicted logical observable flip, 0 or 1
```

The data comes from:

```text
Stim circuit = surface_code:rotated_memory_z
distance = 3
rounds = 5
physical error probability p = 0.02
labels = logical observable flips sampled by Stim
control decoder = PyMatching MWPM
```

The main question was whether a learned GNN decoder could approach or beat MWPM on the same saved test shots.

## Run 1: First Working GNN Baseline

The first implementation used an active-defect graph. In this representation, each shot becomes a graph containing only the detectors that fired.

```text
detector vector = [0, 0, 1, 0, 1, ...]
graph nodes = detector 2, detector 4
```

Node features:

```text
normalized x coordinate
normalized y coordinate
normalized time coordinate
normalized detector index
```

Edges were built with a simple k-nearest-neighbor rule in detector-coordinate space. The model used three GCN layers, masked graph pooling, dropout, and a dense classifier head.

Result:

```text
GNN accuracy = 0.560000
MWPM accuracy = 0.740000
```

This confirmed the pipeline worked end to end, but it also showed that the first graph representation was losing useful information. Inactive detectors were not represented at all, and the k-nearest-neighbor edges were only a heuristic approximation of the physical detector graph.

## Run 2: Fixed Detector-Location Graph

The next step was to make the graph representation more faithful to the QEC structure. Instead of only including active defects, every possible detector location became a node in every shot.

```text
Run 1 graph = sparse active detector events
Run 2 graph = fixed detector-location graph
```

This means each detector node receives a feature saying whether it fired:

```text
node feature = detector_bit, x, y, t, detector_index, DEM_degree, boundary_count
```

This preserved both active and inactive syndrome information. It also removed the need to guess graph size from the number of defects in a shot.

The edge construction was also improved. Instead of k-nearest-neighbor edges, the graph topology was derived from Stim's detector error model. This better reflects which detector pairs can be triggered by the same underlying physical fault.

During this stage, a graph-construction issue was found and fixed. Stim detector error model instructions can contain separated target groups such as:

```text
D1 D5 ^ D4
```

Those groups should not be treated as one fully connected clique. Respecting the target groups reduced the detector-detector graph from an over-connected version to a cleaner detector-error-model graph.

The model was upgraded to a residual GCN:

```text
input projection
residual GCN blocks
layer normalization
dropout
masked mean pooling
masked max pooling
flattened detector summary
dense classifier
validation-tuned threshold
```

Result:

```text
GNN accuracy = 0.693467
MWPM accuracy = 0.760800
```

This was a large improvement over Run 1, but it still did not beat MWPM. The conclusion was that the data was learnable, because MWPM performed well, but the supervised GNN still needed stronger inductive bias and better optimization.

## Run 3: Optimized Residual GNN Decoder

The final iteration focused on making the GNN more decoder-like rather than just a generic classifier over graph features.

The main improvements were:

```text
deeper residual message passing
skip connections to preserve raw detector bits
explicit boundary-aware features
DEM-derived detector graph topology
validation-tuned logical-flip threshold
larger training set
stronger regularization
more stable pooling head
```

The key architectural idea was the residual GCN block:

```text
output = input + GCN(input, adjacency)
```

This lets detector nodes keep their original syndrome information while also receiving messages from nearby detector nodes. That is important for QEC because logical errors are often encoded in global space-time patterns, but the local detector bits should not be washed out by repeated message passing.

The final model also kept a direct raw-syndrome skip path. This meant the classifier could use both:

```text
message-passed graph features
raw detector-bit pattern
```

This was useful because not all information should be forced through the GCN neighborhood aggregation. Some logical-flip evidence may appear as a global syndrome pattern that the dense head can use directly.

Run 3 result:

```text
GNN accuracy = 0.800000
GNN logical prediction error = 0.200000

MWPM accuracy = 0.760800
MWPM logical prediction error = 0.239200
```

This means the optimized GNN beat the MWPM control by roughly 4 percentage points on accuracy:

```text
accuracy improvement over MWPM = +0.039200
relative error reduction = about 16%
```

## Why The Final Model Helped

The improvement came from combining QEC-specific structure with standard GNN optimization tricks.

The fixed detector graph helped because the model no longer threw away inactive detectors. In QEC, the absence of a detection event is also information.

The detector-error-model topology helped because it gave the GNN physically meaningful edges. Instead of connecting detectors only by geometric closeness, the graph connected detectors that can be jointly triggered by the same error mechanism.

Residual blocks helped because deeper message passing became easier to optimize. Without skip connections, repeated GCN layers can over-smooth detector features and make nodes look too similar. With residual connections, local syndrome information can survive through the network.

Boundary features helped because some detector events should be matched to a boundary instead of another detector. MWPM uses this idea naturally, so adding boundary-related features gave the GNN more of the same decoding context.

Validation-tuned thresholding helped because logical flips are not perfectly balanced. A fixed threshold of `0.5` is not always optimal for minimizing logical prediction error.

## Final Comparison

```text
Run 1:
  graph = active-defect KNN graph
  model = simple GCN
  GNN accuracy = 0.560000
  MWPM accuracy = 0.740000
  result = GNN underperformed

Run 2:
  graph = fixed detector-location DEM graph
  model = residual GCN
  GNN accuracy = 0.693467
  MWPM accuracy = 0.760800
  result = GNN improved but still underperformed

Run 3:
  graph = fixed detector-location DEM graph with boundary features
  model = optimized residual GCN with skip connections
  GNN accuracy = 0.800000
  MWPM accuracy = 0.760800
  result = GNN beat the legacy/control decoder
```

## Takeaway

The first GNN proved the pipeline but was too simple. The second GNN showed that the graph representation matters: preserving all detector locations and using detector-error-model edges made a large difference. The optimized residual GNN then combined QEC-aware features with stronger GNN training tricks and crossed the MWPM baseline.

The main lesson is that a GNN decoder needs both:

```text
QEC structure: detector graph, boundaries, space-time coordinates, DEM edges
GNN structure: residual message passing, skip connections, pooling, threshold tuning
```

Together, these changes moved the model from an underperforming prototype to a decoder that can outperform the legacy MWPM baseline in this experimental setting.
